# Capability: C1 智能问答引擎

## User Goal

用自然语言提问，获得准确、即时的车书答案。无需翻阅章节，开口即问，即时得到答案。

## Service Personas

P1 - 卡车司机, P2 - 车队管理员, P3 - 潜在购车用户

## Core Values Contributed

- 即时响应 — 流式渲染，首字响应 < 3 秒
- 精准权威 — 基于云端车书 RAG 知识库
- 交互友好 — 欢迎语引导、拒识场景有兜底

## Scope

**Includes:**
- 文字输入与发送
- 流式答案渲染（逐字上屏，含加载动画）
- 域内已有图片素材附带展示
- 欢迎语与初始问题引导
- 拒识引导（文案 + 建议追问）
- 关键词条推荐（运营配置，固定展示）
- 常用问题 FAQ（按模块分类，固定展示，收集点击数据用于意图分析）
- 快捷追问（拒识后展示 2-3 个建议问题）

**Excludes:**
- 语音识别输入（仅文字）
- 图文生成（仅用已有素材）
- 离线问答（依赖云端）

## Dependencies

None

## Priority

P0

## Priority Justification

没有问答引擎，整个产品不存在。这是核心价值交付的基础。

## Conceptual Scenes（概念化场景）

| ID | 场景名称 | 触发情境 | 关键活动 |
|---|---|---|---|
| ~S1 | 首次进入 | 点击悬浮小机器人 | 展示欢迎语 + 初始问题模块 + 常用问题 FAQ |
| ~S2 | 文字提问 | 用户输入问题并发送 | 文字发送、加载动画、流式答案逐字上屏 |
| ~S3 | 答案拒识 | 云端返回"未找到"或"配置不支持" | 展示拒识文案 + 2-3 个建议追问 |
| ~S4 | 关键词条入口 | 进入页面，固定位置展示 | 运营配置的关键词条（新闻/新功能），点击发送对应问题 |
| ~S5 | 常用问题浏览 | 进入页面，欢迎语下方 | 按模块分类展示固定 FAQ，点击发送；后台收集点击数据 |

> `~S` 前缀表示概念化 Scene，进入 journey-designer 后正式化为 Journey Phases。
