# Feature: F6 语音播报播放控制

## Description

语音播报答案时，提供暂停/继续/停止控制，用户可自由控制播报进度，不必干等完整播完。

## Source

- **Capability**: C3 - 答案交互与反馈
- **Journey**: J1 Phase 4 - 获得答案与操作
- **~F Reference**: C3 ~F9 语音播报 — ✅ verified

## Problem Solved

当前语音播报一条长答案可能要 30 秒，用户没有暂停/停止控制，只能干等或退出（J1 Pain Point #7）。

## User Value

卡车场景下用户可能同时在开车，需要能随时暂停播报，听完关键部分即可停止，不必被迫听完。

## Scope

**Includes:**
- 播报中展示暂停/继续按钮
- 播报中展示停止按钮
- 播报完成自动收起

**Excludes:**
- 倍速播放（后续迭代）
- 进度条拖拽（后续迭代）

## Phase

MVP

## Dependencies

None
