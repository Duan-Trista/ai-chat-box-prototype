# AI 助手初始页面 — PRD

> **版本**: W52 | **日期**: 2026-09-04 | **状态**: Draft

---

## 1. 概述

AI 助手页面根据用户状态展示三种不同界面：引导态、聊天态、隐私态。聊天记录本地存储，多入口共享。

---

## 2. 页面状态

### 2.1 状态定义

| 状态 | 触发条件 | 展示内容 |
|------|---------|---------|
| 引导态 | 首次使用 / 聊天记录为空 | 欢迎语 + 分类 FAQ + 关键词条 |
| 聊天态 | 有聊天记录（localStorage 不为空） | 最后一条问答 + 关键词条，上拉加载更多 |
| 隐私态 | 首次使用，隐私未同意 | 在引导态之上弹出隐私弹窗 |

### 2.2 状态判断流程

```
用户点击悬浮按钮 → 进入 AI 助手页
        │
        ├── 隐私未同意？
        │       │
        │       ├── 是 → 展示引导态，同时弹出隐私弹窗（隐私态）
        │       │         │
        │       │     ┌───┴───┐
        │       │   "同意"  "不同意"
        │       │     │       │
        │       │     ▼       ▼
        │       │  关闭弹窗  关闭弹窗
        │       │  留在引导态 返回入口页
        │       │
        │       └── 否 → 继续
        │
        └── 有聊天记录？
                │
                ├── 是 → 展示聊天态
                └── 否 → 展示引导态
```

### 2.3 状态转换

| 操作 | 原状态 | 新状态 | 说明 |
|------|--------|--------|------|
| 用户发送第一条消息 | 引导态 | 聊天态 | 消息写入 localStorage |
| 用户点击"新对话" | 聊天态 | 引导态 | 先弹确认弹窗，确认后清空 localStorage |
| 上拉加载更多 | 聊天态 | 聊天态 | 追加历史消息，不改变状态 |
| 上拉到底 | 聊天态 | 聊天态 | 展示"没有更多了" |
| 换设备/卸载重装 | 聊天态 | 引导态 | localStorage 丢失 |
| 同意隐私协议 | 隐私态 | 引导态 | 关闭弹窗，留在当前页 |

## 3. 引导态

### 3.1 布局

**导航栏**（页面顶部）：
- 左侧：返回按钮，点击回到入口页（车书模块页面）
- 中间：车辆信息（车牌号 + 车型简称），支持点击切换车辆
- 右侧："新对话"按钮，始终展示

**欢迎区**（页面中部，垂直居中偏上）：
- 机器人图标，48px，居中
- 欢迎语文案："你好，我是卡车助手，有什么可以帮你的？"，17px，白色，加粗，居中

**分类标签栏**（欢迎区下方）：
- 3 个标签横向排列：车书、保养、用车
- 默认选中"车书"，选中态金色背景+白色文字，未选中灰色背景
- 点击标签切换 FAQ 列表，纯前端切换，无网络请求

**FAQ 列表**（标签栏下方）：
- 每个问题一行，左侧"?"图标，右侧问题文本
- 每个问题可点击，点击后作为用户消息发送，进入聊天态
- FAQ 点击数据需上报埋点

**关键词条**（输入框上方）：
- 横向排列，超出屏幕宽度可左右滑动
- 固定展示，引导态和聊天态均有
- 无配置时不展示，不占位

**输入区**（页面底部）：
- 输入框 placeholder："输入您的问题..."
- 右侧发送按钮，空内容置灰不可点击

### 3.2 欢迎语

- 文案："你好，我是卡车助手，有什么可以帮你的？"
- 位置：页面垂直居中偏上
- 样式：17px，白色，加粗
- 机器人图标：48px，在欢迎语上方

### 3.3 分类标签栏

- 一期标签：车书、保养、用车
- 默认选中：车书
- 标签样式：未选中灰色背景，选中金色背景+白色文字
- 切换行为：点击标签切换 FAQ 列表，无网络请求，纯前端切换

### 3.4 FAQ 列表

- 每个分类下预置 3-4 个问题
- 每个问题可点击，点击后作为用户消息发送
- 点击后进入聊天态，FAQ 不再展示
- FAQ 点击数据需上报埋点

**一期 FAQ 配置**：

| 分类 | 问题 |
|------|------|
| 车书 | 如何换挡？、如何实名认证？、为什么要实名认证？、如何调节后视镜？ |
| 保养 | 首保什么时候做？、保养周期是多久？、机油需要换什么型号？ |
| 用车 | 如何查看续航里程？、充电时能开空调吗？、冬季续航会减少多少？ |

## 4. 聊天态

### 4.1 布局

**导航栏**（页面顶部）：
- 左侧：返回按钮，点击回到入口页
- 中间：车辆信息（车牌号 + 车型简称）
- 右侧："新对话"按钮，始终展示

**对话区**（页面中部，填充剩余空间）：
- 用户消息：右对齐，金色气泡，最大宽度 78%
- AI 答案：左对齐，AI 头像 + 灰色气泡，底部展示答案操作按钮（点赞/不点赞、复制、语音播报）
- 答案末尾展示免责声明："内容由AI生成，仅供参考"
- 顶部可上拉触发加载更多历史消息

**关键词条**（输入框上方）：
- 横向排列，超出屏幕宽度可左右滑动
- 固定展示

**输入区**（页面底部）：
- 输入框 placeholder："输入您的问题..."
- 右侧发送按钮，空内容置灰不可点击
- 流式输出中发送按钮变为停止按钮（⏹ 图标），禁止发送新消息

### 4.2 进入时展示规则

- 默认展示最后一条问答（用户消息 + AI 答案）
- 滚动到最底部
- 输入框可用，焦点不自动获取
- 关键词条展示

### 4.3 上拉加载更多

- 用户上滑到对话区顶部 → 展示"下拉加载更多..."
- 加载中：展示"加载中..." + 转圈动画
- 加载完成：更早消息追加到顶部，滚动位置保持
- 所有历史已加载：展示"没有更多了"，不再触发请求
- 加载失败：展示"加载失败，点击重试"

### 4.4 点击"新对话"

```
用户点击"新对话"
       │
       ├── 当前为引导态（无记录）
       │       │
       │       └── toast "已经是新对话"，不做任何操作
       │
       └── 当前为聊天态（有记录）
               │
               ▼
        弹出确认弹窗
        "开启新对话将清空当前聊天记录，确认？"
               │
          ┌────┴────┐
        "取消"    "确认"
          │         │
          ▼         ▼
        留在当前  清空 localStorage
                  展示引导态
                  toast "已开启新对话"
```

## 5. 隐私态

- 引导态渲染完成后，弹出隐私协议弹窗覆盖整个页面
- 弹窗详情见《隐私协议模块 PRD》
- 用户点击"同意"：关闭弹窗，留在引导态
- 用户点击"不同意"：关闭弹窗，返回入口页（车书模块页面）

## 6. 聊天记录存储

### 6.1 存储方案

| 维度 | 说明 |
|------|------|
| 存储方式 | localStorage |
| 存储 Key | `truckAssistantChatHistory` |
| 数据格式 | JSON 数组 |
| 保留策略 | 永久保留，直到用户点击"新对话"清空 |
| 丢失场景 | 换设备、卸载重装、清除 App 数据/缓存 |

### 6.2 数据结构

```json
[
  {
    "role": "user",
    "content": "方向盘怎么调？",
    "timestamp": 1693728000
  },
  {
    "role": "assistant",
    "content": "方向盘调节步骤如下：\n\n1. 找到方向盘下方的调节杆...",
    "images": [],
    "links": [{"text": "车书第3.2.1章节", "url": "app://manual/3.2.1"}],
    "timestamp": 1693728010
  }
]
```

### 6.3 多入口共享

- 车辆Tab、我的Tab、服务Tab 的车书模块进入 → 读写同一份 localStorage
- 从任意入口清空记录 → 所有入口同步清空

## 7. 横向滚动关键词条

### 7.1 展示规则

- 位置：输入框上方，固定展示
- 布局：横向排列，超出屏幕宽度可左右滑动
- 引导态和聊天态均展示
- 无配置时不展示，不占位
- 数据来源：云端配置接口（见云端需求文档 4.1）

### 7.2 交互

- 点击关键词条 → 以用户消息形式发送对应问题
- 点击后进入聊天态（如当前为引导态）
- 点击数据需上报埋点

## 8. 边界场景

| 场景 | 处理 |
|------|------|
| 聊天记录仅 1 条 | 展示该条，上拉展示"没有更多了" |
| 聊天记录数据损坏 | 降级为引导态，不报错 |
| 用户快速反复点击"新对话" | 按钮防抖，300ms 内不可重复点击 |
| 从不同入口反复进入 | 始终看到同一份记录，状态一致 |
| 用户杀进程再进入 | 聊天记录仍在，回到聊天态 |
| 首次进入 + 隐私未同意 | 引导态 + 隐私弹窗（隐私态） |
| 首次进入 + 隐私已同意（清除缓存但未清记录） | 聊天态（记录仍存在） |
| 隐私弹窗中杀进程 | 下次进入重新弹出隐私弹窗 |
| 隐私弹窗中切后台再回来 | 弹窗保持展示，不消失 |
| "新对话"确认弹窗中切后台 | 回来后弹窗仍展示，不自动关闭 |
| 关键词条加载失败 | 不展示关键词条区域，不阻塞页面 |
| 历史消息中图片 URL 已失效 | 展示占位图，不展示裂图 |
| 隐私弹窗展示时，点击遮罩 | 不关闭弹窗，必须点击按钮 |
| 隐私弹窗展示时，输入框 | 不可操作，发送按钮置灰 |
| 隐私弹窗展示时，物理返回键 | 不关闭弹窗，不返回 |
| FAQ / 关键词条重复点击 | 300ms 防抖，只发送一次 |
| 返回按钮跳转 | 回到入口页（车辆Tab/我的Tab/服务Tab 的车书模块） |

## 9. 埋点

| 事件 | 触发时机 | 字段 |
|------|---------|------|
| 进入 AI 助手页 | 页面加载完成 | user_id, entry_source, has_history, timestamp |
| 展示引导态 | 引导态渲染完成 | user_id, timestamp |
| 展示聊天态 | 聊天态渲染完成 | user_id, message_count, timestamp |
| 点击 FAQ | 点击 FAQ 问题 | user_id, faq_category, faq_question, timestamp |
| 点击关键词条 | 点击关键词条 | user_id, keyword_text, timestamp |
| 点击"新对话" | 确认弹窗点击"确认" | user_id, cleared_message_count, timestamp |
| 上拉加载更多 | 触发加载 | user_id, loaded_count, timestamp |
| 上拉到底 | 展示"没有更多了" | user_id, timestamp |
