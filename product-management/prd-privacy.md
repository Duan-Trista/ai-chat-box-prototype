# 隐私协议模块 — PRD

> **版本**: W52 | **日期**: 2026-09-04 | **状态**: Draft

---

## 1. 概述

用户在首次使用卡车助手时，必须阅读并同意隐私协议后才能使用。隐私协议弹窗在助手页内弹出，用户同意后本地记录状态，后续不再重复展示。

---

## 2. 触发条件

| 条件 | 行为 |
|------|------|
| 用户首次进入卡车助手 | 弹出隐私协议弹窗 |
| 用户已同意过隐私协议 | 跳过，直接进入对话页 |
| 用户清除 App 数据/缓存 | 视为首次，重新弹出 |
| 用户卸载重装 App | 视为首次，重新弹出 |

---

## 3. 交互流程

```
用户点击悬浮按钮
       │
       ▼
进入卡车助手页（对话页）
       │
       ├── 已同意过 ──→ 直接进入对话
       │
       └── 首次进入 ──→ 弹出隐私协议弹窗
                            │
                            ├── 点击"同意并继续"
                            │       │
                            │       ├── 记录同意状态（sessionStorage）
                            │       └── 关闭弹窗，进入对话页
                            │
                            └── 点击"不同意"
                                    │
                                    ├── 关闭弹窗
                                    ├── 返回上一页（车书模块）
                                    └── toast "请同意隐私协议后继续使用"
```

## 4. UI 规格

### 4.1 弹窗样式

- 类型：模态弹窗，覆盖整个对话页
- 遮罩层：半透明黑色背景（rgba(0,0,0,0.75)）
- 弹窗卡片：居中展示，圆角 18px，最大宽度 320px
- 内容区：可滚动，最大高度 150px

### 4.2 文案

**标题**：隐私协议

**正文**：
> 感谢您使用卡车助手。我们重视您的隐私和数据安全。
>
> 1. 数据采集：当您使用AI问答功能时，我们会采集您的对话内容、FAQ点击数据，用于优化答案质量。
>
> 2. 数据使用：采集的数据仅用于提升服务质量，不会用于其他商业用途。
>
> 3. 数据安全：您的个人信息和车辆数据将受到严格保护，不会泄露给第三方。
>
> 4. 车辆信息：您的VIN码仅用于匹配知识库，不会在APP端持久化存储。

**按钮**：
- 次要按钮："不同意"（灰色背景）
- 主要按钮："同意并继续"（金色背景）

### 4.3 隐私协议查看入口

在对话页中提供隐私协议查看入口，方便用户随时查阅。

- 位置：对话页右上角或设置菜单中
- 点击后弹出隐私协议全文（同首次弹窗内容，但无"不同意"按钮，仅"关闭"按钮）

## 5. 状态管理

### 5.1 存储方案

| 方案 | 说明 |
|------|------|
| 当前方案 | sessionStorage，浏览器标签页关闭即清除 |
| 建议方案 | localStorage，持久化存储，关闭 App 后仍保持 |

> **决策**：一期使用 sessionStorage，原因：实现简单，无需接入持久化存储。后续若发现用户频繁重新授权，切换为 localStorage。

### 5.2 状态 Key

```
key: "privacyAccepted"
value: "true"
```

### 5.3 状态判断时机

- 进入对话页时，页面渲染前判断
- 判断逻辑：`sessionStorage.getItem('privacyAccepted') === 'true'`
- 未取得或值为 `null`：展示弹窗
- 值为 `true`：跳过弹窗

## 6. 边界场景

| 场景 | 处理 |
|------|------|
| 隐私弹窗展示中，用户点击物理返回键 | 关闭弹窗，返回上一页，不 toast |
| 隐私弹窗展示中，用户切后台 | 弹窗状态保持，返回前台继续展示 |
| 隐私弹窗展示中，用户杀进程 | 下次进入重新触发弹窗 |
| 用户已同意，但清除了 App 缓存 | 重新触发弹窗 |
| 用户从不同入口进入（车辆Tab/我的Tab/服务Tab 的车书页） | 行为一致，不同意时返回对应入口页面 |
| 网络异常时进入 | 隐私弹窗为纯本地逻辑，不受网络影响 |

## 7. 埋点

| 事件 | 触发时机 | 字段 |
|------|---------|------|
| 隐私协议展示 | 弹窗弹出时 | user_id, timestamp |
| 同意隐私协议 | 用户点击"同意并继续" | user_id, timestamp |
| 拒绝隐私协议 | 用户点击"不同意" | user_id, timestamp |

---

## 8. 依赖

- 无外部依赖
- 纯客户端逻辑，不涉及接口调用

---

## 9. 非功能性需求

| 指标 | 要求 |
|------|------|
| 弹窗弹出延迟 | < 200ms（页面渲染后） |
| 同意状态读写 | 同步，不阻塞渲染 |
| 异常处理 | 存储 API 不可用时，降级为每次弹出（允许用户使用但不记录状态） |
