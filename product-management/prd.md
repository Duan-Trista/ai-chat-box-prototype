# AI Assistant Chatbox MVP1 — 产品需求文档 (PRD)

> **版本**: MVP1 | **日期**: 2026-09-04 | **状态**: 正式评审版 | **产品经理**: TBD

---

## 1. 项目背景

当前用户查阅车辆功能、故障说明、保养信息时，需要在纸质车书或电子车书中手动检索，查找成本高、效率低。

通过引入 AI Assistant，用户可直接使用自然语言提问，快速获取官方车书内容，提高问题获取效率和用户体验。

**MVP1 定义**：用户无需翻阅车书，通过自然语言即可快速获得官方、可信、可追溯的车辆知识答案；当 AI 无法处理问题时，可一键拨打 400 客服获取帮助。

---

## 2. 产品目标

### 2.1 产品目标

帮助用户通过自然语言快速获取官方、准确、可追溯的车辆说明信息。

当 AI 无法解决用户问题时，为用户提供 400 客服兜底服务，确保用户获得进一步帮助。

### 2.2 MVP1 目标

验证用户是否愿意通过 AI 查询车书内容，并建立基础 AI 问答体验。

### 2.3 目标用户

| 角色 | 场景 | 核心诉求 |
|------|------|---------|
| P1 卡车司机 | 驾驶中遇到功能操作、报警灯等问题 | 快速获得准确答案，不停车、不翻书、不等人 |
| P2 车队管理员 | 协助司机解答车辆问题 | 减少重复解答，降低沟通成本 |
| P3 潜在购车用户 | 了解车辆配置、功能、参数 | 自助获取信息，辅助购车决策 |

## 4. 页面结构

### 4.1 页面组成

**导航栏**（页面顶部）：
- 左侧：返回按钮，点击回到入口页（车书模块页面）
- 中间：页面标题"AI Chat Box" + 车辆信息（车牌号 + 车型简称），支持点击切换车辆
- 右侧："新对话"按钮，始终展示

**消息展示区域**（页面中部，填充剩余空间）：
- 用户消息：右对齐，金色气泡，最大宽度 78%
- AI 答案：左对齐，AI 头像 + 灰色气泡，底部展示答案操作区
- 系统提示：居中灰色文字
- 支持历史消息滚动浏览，顶部可上拉加载更多

**推荐问题区域**（消息区下方）：
- 引导态、拒识态展示
- 展示内容由云端配置下发

**关键词条**（输入框上方）：
- 横向排列，超出屏幕宽度可左右滑动
- 引导态和聊天态均展示，无配置时不展示不占位

**输入区域**（页面底部）：
- 输入框 + 发送按钮，固定显示
- 输入框 placeholder："输入您的问题..."

## 5. 页面状态定义

### 5.1 引导态

**触发条件**：首次使用 / 无聊天记录 / 用户点击"新对话"后

**展示内容**：
- 导航栏
- AI 头像 + 欢迎语："你好，我是 Scania 智能助手，关于车辆使用的问题都可以问我。"
- 分类标签栏（车书/保养/用车，默认选中"车书"，选中态金色高亮）
- 推荐问题列表（FAQ），每个问题可点击发送
- 关键词条（横向滚动）
- 输入框 + 发送按钮

### 5.2 聊天态

**触发条件**：存在历史聊天记录

**展示内容**：
- 导航栏
- 历史消息（默认定位到最新消息）
- 关键词条（横向滚动）
- 输入框 + 发送按钮

### 5.3 提问中状态

**触发条件**：用户点击发送后

**页面表现**：
- 展示用户问题气泡
- 发送按钮置灰，防止重复提交
- 输入框清空

### 5.4 AI 生成中状态

**触发条件**：AI 开始返回内容

**页面表现**：
- 展示思考动画（跳动圆点 + 两阶段文案："正在查找车书..." → "正在组织答案..."）
- 流式逐字输出答案，附带闪烁光标
- 对话区自动滚动到最新内容
- 发送按钮变为停止按钮（⏹ 图标），禁止发送新消息
- 答案操作按钮（点赞/不点赞、复制、语音播报）在首个字符上屏后展示

### 5.5 回答完成状态

**触发条件**：AI 返回完成

**页面表现**：
- 闪烁光标消失
- 展示完整答案 + 来源引用
- 展示答案操作区（点赞/不点赞、复制、语音播报）
- 展示快捷追问
- 答案底部展示免责声明："内容由AI生成，仅供参考"
- 停止按钮恢复为发送按钮

### 5.6 拒识状态

**触发条件**：AI 无法回答问题

**展示内容**：
- 拒识文案："抱歉，我暂时无法回答该问题。"
- 推荐问题（2-3 个）
- 400 客服电话入口

### 5.7 状态判断流程

```
用户点击悬浮按钮 → 进入 AI 助手页
        │
        ├── 隐私未同意？
        │       │
        │       ├── 是 → 展示引导态，同时弹出隐私弹窗
        │       │         │
        │       │     ┌───┴───┐
        │       │   "同意"  "不同意"
        │       │     │       │
        │       │     ▼       ▼
        │       │  关闭弹窗  关闭弹窗
        │       │  留在引导态 返回入口页
        │       │
        │       └── 否 → 继续
        │
        └── 有聊天记录？
                │
                ├── 是 → 展示聊天态
                └── 否 → 展示引导态
```

### 5.8 状态转换

| 操作 | 原状态 | 新状态 | 说明 |
|------|--------|--------|------|
| 用户发送第一条消息 | 引导态 | 提问中 → AI生成中 → 回答完成 | 消息写入 localStorage |
| 用户点击"新对话" | 聊天态/回答完成 | 引导态 | 先弹确认弹窗，确认后清空 localStorage |
| 上拉加载更多 | 聊天态 | 聊天态 | 追加历史消息，不改变状态 |
| 上拉到底 | 聊天态 | 聊天态 | 展示"没有更多了" |
| 换设备/卸载重装 | 聊天态 | 引导态 | localStorage 丢失 |
| 同意隐私协议 | 隐私态 | 引导态 | 关闭弹窗，留在当前页 |
| AI 拒识 | AI生成中 | 拒识态 | 展示拒识文案 + 推荐问题 + 400 |

## 6. 功能需求

### 6.1 C1 智能问答引擎

#### 6.1.1 文本提问

用户可通过自然语言输入问题，支持：车辆功能问题、故障说明问题、保养维护问题、使用说明问题。

#### 6.1.2 AI 问答

系统完成：问题理解 → 知识检索 → 答案生成 → 流式输出。

**流式渲染**：
- 加载阶段：思考动画（跳动圆点 + 两阶段文案）
- 流式阶段：逐字上屏 + 闪烁光标 + 自动滚动
- 完成阶段：完整答案 + 来源引用 + 答案操作区 + 免责声明
- 图片处理：答案中图片 URL 内嵌展示，加载失败展示占位图 + "图片加载失败"提示 + "点击重试"
- 中断：用户点击停止按钮 → 已生成内容保留，输入框恢复

#### 6.1.3 多轮上下文

支持连续提问，系统自动结合当前会话历史理解问题。例如：用户询问"保养周期"后追问"后续呢？"→ 系统需结合上一轮问题进行理解。

- 上下文超时：切后台超过 5 分钟 → 自动新会话
- 点击"新对话" → 弹出确认弹窗 → 确认后清空本地聊天记录 → 展示引导态

#### 6.1.4 推荐问题（FAQ）

推荐问题由云端配置下发。

展示场景：首次进入、新对话、拒识后。

展示形式：分类标签栏（车书/保养/用车）+ 问题列表，每个问题可点击发送。

**一期 FAQ 配置**：

**已绑车用户**：

| 分类 | 问题 |
|------|------|
| 车书 | 如何换挡？、如何调节后视镜？、方向盘怎么调节？ |
| APP操作 | 怎么绑车？、如何进行车联网卡实名认证？、车辆识别代码（VIN）在哪里？ |

**未绑车用户**：

| 分类 | 问题 |
|------|------|
| 车型介绍 | NEXT ERA E27 有什么配置？、Scania 卡车有哪些优势？、如何绑定车辆？ |
| APP操作 | 怎么绑车？、如何进行车联网卡实名认证？、车辆识别代码（VIN）在哪里？ |

#### 6.1.5 快捷追问

回答结束后展示相关问题推荐，点击后直接发起新问题。

#### 6.1.6 拒识处理

触发场景：超出知识库范围、知识库无匹配内容、问题无法理解、服务返回拒答。

统一展示拒识文案："抱歉，我暂时无法回答该问题。"，同时展示推荐问题 + 400 客服电话。

| 场景 | 处理 |
|------|------|
| 敏感/违规 | 展示文案，不展示建议追问 |
| 法规合规 | 展示文案，建议咨询官方渠道 |
| 人身攻击 | 展示文案，引导正常提问 |
| 紧急安全 | 展示紧急处理建议 + 400 电话入口 |
| 投诉抱怨 | 展示道歉 + 400 电话入口 |
| 竞品比较 | 引导到 Scania 车型介绍 |
| 模糊问题 | 引导具体描述 + 展示建议追问 |
| 超出知识库 | 展示文案 + 400 电话入口 |
| 重复问题 | 提示换方式提问 + 400 电话入口 |
| 普通拒识 | 展示文案 + 2-3 个建议追问 |

#### 6.1.7 400 客服兜底

触发场景：AI 拒识、AI 服务异常、回答失败。

点击后弹出拨号确认框，用户确认后调用系统拨号能力。

### 6.2 C2 对话体验管理

#### 6.2.1 单会话模式

MVP1 采用单会话模式。用户仅拥有一个聊天窗口，所有聊天记录共享存储，不支持多会话。

#### 6.2.2 历史记录展示

用户再次进入页面时，自动展示历史聊天记录，默认定位至最新消息。

#### 6.2.3 上拉加载历史

历史消息较多时支持分页加载，用户上拉查看早期消息。

- 加载中：展示"加载中..."
- 加载完成：更早消息追加到顶部，滚动位置保持
- 所有历史已加载：展示"没有更多了"，不再触发请求
- 加载失败：展示"加载失败，点击重试"

#### 6.2.4 新对话

```
用户点击"新对话"
       │
       ├── 当前为引导态（无记录）
       │       │
       │       └── toast "已经是新对话"，不做任何操作
       │
       └── 当前为聊天态（有记录）
               │
               ▼
        弹出确认弹窗
        "开启新对话将清空当前聊天记录，确认？"
               │
          ┌────┴────┐
        "取消"    "确认"
          │         │
          ▼         ▼
        留在当前  清空 localStorage
                  展示引导态
                  toast "已开启新对话"
```

#### 6.2.5 会话恢复

用户离开页面并再次进入，系统恢复：历史消息、滚动位置、当前会话状态。

#### 6.2.6 聊天记录存储

| 维度 | 说明 |
|------|------|
| 存储方式 | localStorage |
| 存储 Key | `truckAssistantChatHistory` |
| 数据格式 | JSON 数组 |
| 保留策略 | 永久保留，直到用户点击"新对话"清空 |
| 丢失场景 | 换设备、卸载重装、清除 App 数据/缓存 |
| 多入口共享 | 车辆Tab/我的Tab/服务Tab 进入 → 同一份记录 |

### 6.3 C3 答案交互与反馈

#### 6.3.1 语音播报

支持将答案转换为语音播放。

- 播放：点击播放按钮开始播报
- 暂停：点击暂停按钮暂停播报
- 继续：再次点击继续播报
- 多条消息：同一时间仅允许播放一条消息，新消息开始播放时自动停止上一条
- 页面退出：退出页面自动停止播放
- 流式输出中可用：播报当前已生成内容

#### 6.3.2 查看原文

点击来源区域，跳转对应车书章节（APP 内车书模块 deeplink）。

## 7. 来源展示规则

### 7.1 功能目标

提升答案可信度，确保用户能够追溯答案来源。

### 7.2 数据来源

来源信息由 Agent 返回。

### 7.3 展示内容

展示：车书名称、章节名称、原文链接。

### 7.4 展示规则

- 有来源时：展示来源模块
- 无来源时：不展示来源模块
- 最多展示 3 条来源，超过 3 条不继续展示
- 来源链接失效时：提示"原文暂不可查看"

---

## 8. 输入框规则

| 规则 | 说明 |
|------|------|
| 输入长度 | 最少 1 个字符，最大 500 字符 |
| 空输入 | 禁止发送，发送按钮置灰 |
| 多行输入 | 自动扩展高度，最多 4 行，超出后滚动 |
| 重复点击发送 | 防重复提交，同一问题仅发送一次 |
| AI 回答过程中 | 发送按钮变为停止按钮（⏹ 图标），禁止发送新消息，待回答结束后恢复 |
| FAQ/关键词条防抖 | 300ms 内重复点击只发送一次 |

## 11. 悬浮入口

### 11.1 展示规则

- 展示页面：车辆Tab、我的Tab、服务Tab 下的车书模块所有页面
- 位置：页面右下角
- 默认展示悬浮小机器人图标

### 11.2 交互行为

- 支持拖拽移动，松手后吸附到左/右侧边缘（距边缘 16px，0.3s 动画）
- 移动距离 < 3px 视为点击，触发进入；>= 3px 视为拖拽
- 拖拽中半透明，不超出屏幕边界
- 位置记忆：跨页面保持上次位置

### 11.3 入口点击流程

```
首次进入 → 进入助手页 → 弹出隐私协议 → 同意 → 展示引导态
                                        → 不同意 → 关闭弹窗，返回入口页
非首次进入 → 进入助手页 → 展示聊天态
```

## 12. 隐私与合规

### 12.1 触发条件

| 条件 | 行为 |
|------|------|
| 用户首次进入卡车助手 | 弹出隐私协议弹窗 |
| 用户已同意过隐私协议 | 跳过，直接进入对话页 |
| 用户清除 App 数据/缓存 | 视为首次，重新弹出 |
| 用户卸载重装 App | 视为首次，重新弹出 |

### 12.2 交互流程

```
进入 AI 助手页 → 引导态渲染完成
        │
        ├── 已同意过 ──→ 直接进入对话
        │
        └── 首次进入 ──→ 弹出隐私协议弹窗
                            │
                            ├── 点击"同意并继续"
                            │       │
                            │       ├── 记录同意状态
                            │       └── 关闭弹窗，进入对话页
                            │
                            └── 点击"不同意"
                                    │
                                    ├── 关闭弹窗
                                    └── 返回入口页（车书模块页面）
```

### 12.3 弹窗 UI

- 类型：模态弹窗，覆盖整个对话页，半透明黑色遮罩（75%），不可点击遮罩关闭
- 弹窗卡片：居中展示，圆角 18px，最大宽度 320px
- 内容区：可滚动，最大高度 150px
- 按钮：次要按钮"不同意"（灰色）+ 主要按钮"同意并继续"（金色）
- 弹窗展示时，输入框不可操作，发送按钮置灰，物理返回键不关闭弹窗

### 12.4 文案

> 感谢您使用卡车助手。我们重视您的隐私和数据安全。
>
> 1. 数据采集：当您使用AI问答功能时，我们会采集您的对话内容、FAQ点击数据，用于优化答案质量。
>
> 2. 数据使用：采集的数据仅用于提升服务质量，不会用于其他商业用途。
>
> 3. 数据安全：您的个人信息和车辆数据将受到严格保护，不会泄露给第三方。
>
> 4. 车辆信息：您的VIN码仅用于匹配知识库，不会在APP端持久化存储。

### 12.5 状态存储

- 存储方式：sessionStorage，key: `privacyAccepted`
- 同意状态：值为 `"true"`
- 判断时机：进入对话页渲染前

### 12.6 免责声明

- 答案底部固定展示："内容由AI生成，仅供参考"
- 日志脱敏：不包含完整 VIN、姓名、手机号

## 13. 异常场景处理

| 异常 | 表现 |
|------|------|
| 网络异常 | toast "网络连接异常，请检查网络后重试"，文本保留在输入框，支持重新发送 |
| 请求超时 (>10s) | 答案气泡展示"当前服务响应超时，请稍后重试" + 重试按钮 |
| AI 服务异常 (5xx) | 答案气泡展示"服务繁忙，请稍后重试" + 重新生成按钮 |
| 切后台恢复 | 5 分钟内恢复对话，超过则新会话 |
| 流式中断 | 展示已接收内容 + "加载中断，点击重试" |
| VIN 无效 | 展示"VIN码无效，请检查车辆信息" |
| 车辆未识别 | 展示"未识别到车辆信息，请联系客服" |
| FAQ 为空 | 隐藏 FAQ 区域 |
| 来源链接失效 | 提示"原文暂不可查看" |
| 本地记录丢失 | 返回引导态 |
| 聊天记录数据损坏 | 降级为引导态，不报错 |

## 14. 边界场景

| 场景 | 处理 |
|------|------|
| 聊天记录仅 1 条 | 展示该条，上拉展示"没有更多了" |
| 用户快速反复点击"新对话" | 按钮防抖，300ms 内不可重复点击 |
| 从不同入口反复进入 | 始终看到同一份记录，状态一致 |
| 用户杀进程再进入 | 聊天记录仍在，回到聊天态 |
| 首次进入 + 隐私未同意 | 引导态 + 隐私弹窗 |
| 首次进入 + 隐私已同意（清除缓存但未清记录） | 聊天态（记录仍存在） |
| 隐私弹窗中杀进程 | 下次进入重新弹出隐私弹窗 |
| 隐私弹窗中切后台再回来 | 弹窗保持展示，不消失 |
| "新对话"确认弹窗中切后台 | 回来后弹窗仍展示，不自动关闭 |
| 关键词条加载失败 | 不展示关键词条区域，不阻塞页面 |
| 历史消息中图片 URL 已失效 | 展示占位图，不展示裂图 |
| 隐私弹窗展示时，点击遮罩 | 不关闭弹窗，必须点击按钮 |
| 隐私弹窗展示时，物理返回键 | 不关闭弹窗，不返回 |
| FAQ / 关键词条重复点击 | 300ms 防抖，只发送一次 |
| 返回按钮跳转 | 回到入口页（车辆Tab/我的Tab/服务Tab 的车书模块） |

## 17. 产品决策

| ID | 决策 |
|----|------|
| PD-01 | MVP1 采用单会话模式，不支持多会话 |
| PD-02 | VIN 切换后不创建新会话，保留当前记录 |
| PD-03 | 来源信息由 Agent 返回 |
| PD-04 | 400 客服采用拨号确认弹窗 |
| PD-05 | FAQ、欢迎语、推荐问题、关键词条由云端配置下发 |
| PD-06 | 聊天记录本地存储（localStorage），换设备/卸载重装后丢失 |
| PD-07 | AI 生成期间禁止发送新问题，发送按钮变为停止按钮 |
| PD-08 | 悬浮按钮仅在车书模块页面展示（车辆Tab/我的Tab/服务Tab） |
| PD-09 | 悬浮按钮支持拖拽 + 边框吸附 + 位置记忆 |
| PD-10 | 隐私协议首次进入时在助手页内弹出，不同意则返回入口页 |
| PD-11 | 引导态/聊天态/拒识态推荐问题由云端配置下发 |
| PD-12 | 语音播报同一时间仅播放一条，新消息播放时自动停止上一条 |
